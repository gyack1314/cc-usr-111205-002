# 收到时延的离散化

support按有限时刻递增，最后一个null代表infinity，且只允许这一个尾原子。普通记录允许L<t<=R，R=null包括所有大于L的有限支撑及infinity；exact_zero仅允许支撑0，left=right=0。普通left=0不包含0，不能与exact_zero混同。

似然是加权记录区间概率之积。CDF在有限t只累计有限支撑<=t；分位为累计概率首次达到alpha的最小支撑，若仅尾原子达到则为infinity。近最优集合loglik>=最佳loglik-drop，drop=0只在声明数值容差内表达最优集合；边界解允许零概率。百分位抽样区间用type-7，出现无限界时保持扩展实数语义，不删除副本。

domain只清点检查区间和整群，不映射支撑或求似然。

## 估计口径（response_data.estimate）

- 目标：在单纯形{p>=0,sum p=1}上最大化 sum_i w_i*log(sum_{j允许于i} p_j)。每条记录允许候选集合必须非空；不被任何记录允许的候选成为结构性零概率组（概率恒为0），不报错删除。
- 似然只通过设计矩阵A的列起作用，相同0/1列的候选点构成同一似然组，组内任意再分配都不改变似然——这是结构性不可识别，多初值与重复候选不得包装成唯一识别。
- EM在活跃似然组（剔除全零列组）上迭代，停止原因取`kkt_residual`或`max_iter`；收敛以单纯形KKT残差为准，参数变化小不单独作为收敛依据。
- 近最优集合是凹似然的水平超集（凸多面体），CDF为线性目标、分位随概率逐格单调，其上下界在多面体顶点取得；实现枚举单纯形顶点、边与水平曲面交点、以及内部最优射线交点。穷举仅适用于配置给定的小支撑。
- 网格整群bootstrap以固定种子有放回抽网格，被抽中网格的全部住户与权重整体复制，每次重新拟合；抽样区间与近最优/不可识别范围是两类不确定性，输出中分开。
- 观察结束与检查过程假设独立于真实时延；若检查时点有意依赖真实时延（有意延迟检查），只能列为假设限制，数据本身无法纠正。
- 概率只定义在配置候选时点上，属离散化分析口径，不声称是连续时间唯一真分布。
